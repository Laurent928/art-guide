界面上会看到的词

Create
开始画图的按钮。在页面右上角，蓝色的。
Model
底模，也就是"画师"。决定整体画风和画质。最重要的一项。
Add Model
点它换底模。会弹出一个模型列表让你搜。
+ Add Additional Resource
添加附加资源，主要用来加 LoRA（画风模型 / 角色模型）。
LoRA
"画风补丁"。加载它，出图就会往某个画风或某个角色靠。旁边通常有数字框，那是权重，一般 0.7~0.9。
Prompt
正向提示词。写你想要什么。
Negative Prompt
负面提示词。写你不想要什么。ChatGPT 没有这一栏，这是 Civitai 的优势。
Draft Mode
草稿模式。开着会让很多高级选项变灰、点不动。遇到"参数调不了"，先关它。
Aspect Ratio
画面比例。SDXL 有三个预设：
Square 1024×1024（方）
Landscape 1216×832（横，画三视图用）
Portrait 832×1216（竖，画单人立绘用）
Steps
步数。AI 画多少笔。太少会糊，太多没用。一般 25~35，建议 30。
CFG Scale
听话程度。太低乱画，太高颜色发糊。Illustrious 系建议 5，别超过 7。
Sampler
采样算法。新手就用 Euler a。
Seed
随机种子。同一个种子 + 同样的提示词 = 同样的图。想复现某张图就把它填进去锁住。
Clip skip
跳过几层文本编码。动漫模型一般用 2。
Denoise / Denoising Strength
图生图的核心参数，决定"保留原图多少"。
0.3 = 几乎不变 · 0.5 = 保设计改画风 · 0.75 = 开始跑 · 0.9+ = 等于重画。
Generate
生成按钮。最下面那个蓝色大按钮。
Remix
别人图片上的按钮。会把你带进生成页，并且把那张图的全部设置一起带进来——包括它用的 ControlNet 和参考图。不知道自己为什么有参考图时，八成是点了这个。
Buzz
Civitai 的站内点数。生成图片会消耗。每天登录会送一些。
Generation data
图片的生成参数。点开一张图就能看到，包括提示词、种子、模型、LoRA。出问题时截图这个发出来最有用。

功能名词

txt2img（纯文字出图）
只给提示词，从零开始画。好处是完全自由，坏处是每次都会重新发明设计。
img2img（图生图）
给一张参考图，让 AI 以它为底稿重画。配合 Denoise 使用，是"保住设计"的正确工具。
ControlNet
把结构、姿势、线条锁死的工具。
常见模式：
· canny — 描边（会把文字和边框也锁进去，慎用）
· openpose — 只管人体姿势
· lineart — 只管线稿
· scribble — 涂鸦，随便画个火柴人就行
它是"锁死"，不是"参考"。想保留设计又想改画风，用图生图而不是它。
Hi-res fix
高清修复。先出一张初稿，再做一次低强度重绘，细节和清晰度会明显变好。基本可以一直开着。
Face fix
修脸。专门重画脸部，眼睛和皮肤细节会好很多。要检测到人脸才生效。也叫 ADetailer / FaceDetailer。
Workflow（工作流）
预设的处理流程。比如"出图 + 高清修复 + 修脸"打包成一个。 Hi-res fix、Face fix 都在这里面。
Checkpoint / Base model
底模。就是 Model 那一栏选的东西。比如 Illustrious、Pony、NoobAI 都是底模系。
Trigger word（触发词）
LoRA 的"开关词"。必须写进提示词，LoRA 才会生效。比如碧蓝幻想画风的是 gbf_style。
Embedding
另一种附加资源，用来加强或压制某些内容。新手一般用不到。
Upscale（放大）
把小图变清晰的大图。不要一开始就出大图，先出 1024 再放大更好。
Inpaint（局部重绘）
只改画面里的一部分，其他不动。修手、修配饰很好用。

可能会看到的其他说法

看到的意思
SDXL一类底模的规格。尺寸在 1024 附近，Illustrious 就是这一类
SD 1.5更老的规格，尺寸 512 附近。LoRA 不能和 SDXL 混用
Pony另一种底模系。它有自己的提示词写法（score_9 那一套）
Illustrious一种动漫底模系。碧蓝幻想画风 LoRA 就是给它做的
Base Model（模型页面上那一栏）LoRA 必须和底模同系。写着 Illustrious 的就配 Illustrious 的底模
safetensors模型文件的格式。安全，优先选它
GGUF压缩过的模型，省显存但慢一点
抽卡行话。同一个提示词多出几张挑好的。这是正常流程，不是你操作错了
过拟合模型学过头了。只能画出训练集里的样子，换个姿势就崩
底模就是 Checkpoint / Model
负面词Negative Prompt 里的内容
