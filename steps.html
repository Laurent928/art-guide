一步步做 参数 训练 改图
0

开始之前，先准备三样

要什么说明
一个浏览器手机用 Safari，电脑用 Chrome 或 Edge
一个邮箱注册 Civitai 账号用，QQ 邮箱就行
20 分钟第一次做要慢一点，之后出图只要 30 秒
⚠️ 不要用微信 / QQ 内置浏览器打开 微信和 QQ 里的内置浏览器会限制一些功能，页面可能显示不全。
请把网址复制出来，用 Safari 或 Chrome 打开。
1

打开浏览器，输入网址

  1. 打开 Safari 或 Chrome
  2. 在最上面的地址栏点一下
  3. 输入 civitai.com
  4. 按回车（手机键盘上是"前往"或"Go"）
打不开 / 一直转圈？ Civitai 在国内有时连不上。
试试：换个网络（比如手机流量）、多刷新几次。
她在美国的话应该能直接打开。
2

登录（或注册）

注册免费，只要邮箱。

还没有账号：先注册

  1. 看页面右上角，找到 Sign In 按钮，点它
  2. 弹出的窗口里，找底部的 Sign Up / Register 字样
  3. 最简单：直接点 Continue with Google 用谷歌账号登（如果有）
  4. 或填邮箱 + 用户名 + 密码，点注册
  5. 去邮箱收验证邮件，点里面的链接

已经有账号：登录

  1. 点右上角 Sign In
  2. 填邮箱和密码，或用 Google 账号登
✅ 怎么知道登上了 原来 Sign In 的位置，会变成你的头像（一个小圆圈）。
看到头像就是登上了。
3

认识一下主界面

不用记全部，认识三个地方就够。

位置是什么
右上角蓝色 Create⭐ 点它才能开始画图，整页最重要的按钮
右上角头像说明你登录了
中间大片图片别人做的图，现在不用管
4

进入生成页面

两种方法，哪个都行。

方法一：点 Create 按钮

  1. 点右上角蓝色的 Create
  2. 画面左侧会滑出一个面板 —— 这就是生成面板

方法二：直接输网址（推荐，更宽敞）

  1. 在地址栏输入 civitai.com/generate
  2. 回车，会进入整屏的生成页面
✅ 怎么知道成功了 页面上出现了这些字：Model、Prompt、Negative Prompt
看到 Prompt 这个词，就说明进对了。
⚠️ 千万不要做的事 不要去看图片墙、点开别人的图、点图上的 Remix 按钮。
点了 Remix 会把那张图的所有设置一起带进来——包括一张你根本不知道的参考图。
你现在遇到的问题，很可能就是这么来的。
5

关掉 Draft Mode（最关键的一步）

不做这步，后面参数全是灰的、点不动 —— 你就会觉得"调不了"。

  1. 在生成页面里从上往下慢慢找
  2. 找到写着 Draft Mode 的那一行
  3. 它右边有个小开关。绿色就是开着
  4. 点一下开关，让它变成灰色
✅ 怎么知道关对了 关掉之后，页面下方会多出来一些原来没有的选项（比如 Steps、CFG Scale）。
看到多出来的选项，就说明关对了。
找不到 Draft Mode？ 在生成面板里往下滚，它一般在参数区域。
找不到就先做下一步，遇到灰色点不动的参数再回来找它。
6

换底模

从原来的基础版，换成强化版。这一步直接决定画质。

  1. 在生成页面最上面找 Model 那一栏
  2. 点它右边的 Add Model 按钮
  3. 会弹出一个大窗口，里面有模型列表
  4. 在窗口的搜索框里输入 PerfectDeliberate
  5. 等它搜出来，点第一个选中
  6. 关闭弹窗（或点确认）
如果搜不到 PerfectDeliberate 改搜 Illustrious XL 2.0，效果也够用。
✅ 怎么知道换对了 Model 那一栏里的名字会变，不再是 "Illustrious-XL" 就对了。
7

加上碧蓝幻想画风模型

如果之前已经加过，跳到第 8 步。

  1. 在 Model 那一栏的下面，找 + Add Additional Resource
  2. 点它，弹出窗口
  3. 搜索框输入 Granblue Fantasy Style
  4. 找到 Granblue Fantasy Style for Pony and Illustrious
  5. 选底模写着 Illustrious 的版本，添加
  6. 添加后它出现在模型栏下面，右边有个数字框（权重）
  7. 把那个数字改成 0.8
对照官方文档原文 Civitai 官方说明里写："+ Add Additional Resource — Additional resources include LoRA…"
所以面板上认 Add Additional Resource 这几个字。
8

改尺寸

有现成预设，不用手动输数字。

  1. 找到 Aspect Ratio 这一栏
  2. 点开它右边的下拉
  3. 选 Landscape (1216×832)
官方文档确认过 SDXL 模型提供三个预设：Square (1024×1024)、Landscape (1216×832)、Portrait (832×1216)。
直接选，不用自己算。
9

改 CFG

  1. 往下找 CFG Scale
  2. 把里面的数字从 7 改成 5
  3. 顺便确认 Steps 是 30（是就不用动）
  4. 确认 Sampler 是 Euler a（是就不用动）
如果根本找不到 CFG Scale 说明 Draft Mode 还开着。回到第 5 步重新关一次。
10

确认没有参考图

这一步是为了确保干净 —— 上一张图就是栽在这里。

看到什么怎么做
写着 ControlNet 的区域点它右上角的 ✕ 删掉
有一张缩略图（不是你上传的）点 ✕ 删掉
Image / Init Image 上传框留空，不要上传任何图
✅ 最简单的保证 只要你是从 civitai.com/generate 重新打开的干净页面，而且一张图都没上传， 那就不可能有 ControlNet。扫一眼确认没有图就可以了。
为什么这么强调 你上一张图的参数里，带着一个 canny 模式的 ControlNet，还挂着一张 1536×1024 的参考图。
那个东西会把画面锁死，画风根本改不动。而你可能完全不知道它在。
11

粘贴提示词

  1. 找到 Prompt 框（大一点的那个）
  2. 把下面正向提示词整段粘进去
  3. 找到 Negative Prompt 框（小一点的）
  4. 把负面提示词整段粘进去
正向提示词 → 粘到 Prompt
gbf_style, character sheet, reference sheet, concept art, turnaround, multiple views, front view, side view, back view, 1girl, solo, long blonde hair, twin braids, blue eyes, blue witch hat, silver crescent hair ornament, blue cloak, blue tunic, white frilled skirt, single wide leather belt, square metal buckle, one diagonal leather strap, leather pouch on hip, dark brown leather thighhighs, over-knee leather stockings, brown leather boots, gold trim, full body, standing, simple background, white background, masterpiece, best quality, very aesthetic, absurdres
负面提示词 → 粘到 Negative Prompt
lowres, bad anatomy, bad hands, extra fingers, fewer fingers, extra arms, extra legs, extra limbs, fused limbs, mutated hands, poorly drawn face, deformed, bad proportions, long neck, duplicate, too many belts, messy belts, cluttered straps, excessive accessories, flat color, blurry, jpeg artifacts, watermark, signature, username, text, worst quality, low quality, normal quality, cropped, out of frame
提示词不用改 这两段就是你上次用的，完全正确，一个字都不用改。上次的问题不在提示词。
12

点生成

  1. 拉到页面最下面
  2. 找到生成按钮（通常写着 Generate，是蓝色的大按钮）
  3. 点它
  4. 等 30 秒左右，图就出来了
如果按钮是灰的、点不动 检查两件事：
① Prompt 框是不是空的（空的不能生成）
② Draft Mode 关了吗（回第 5 步）
13

看结果

✅ 像碧蓝幻想了 🎉 那就成了，完全不用重新训练模型。
⚠️ 还是不像 把新图的参数发过来。

怎么拿参数：
① 在 Civitai 里找到你刚出的那张图
② 点开它
③ 屏幕上找 Generation data 那一块
④ 截图发过来
小建议：打开 Hi-res fix 官方文档提到有个 Hi-res fix 功能，会让细节和清晰度明显变好。
位置在生成页面的工作流（Workflow）选项里。等你先把基础流程跑通了再试。
